# Information needed to connect Norwich's utilities

Please send a utility inventory before the full 300-offtaker onboarding package, if available. This lets us identify shared portals and start the integrations that cover the most accounts.

For each utility, we need:

- Full utility name, state, customer-portal URL and approximate number of affected offtakers/arrays.
- Whether each invoice is based on producing-meter generation, the customer's utility credit or a utility allocation statement; include billing cadence.
- Two consecutive closed cycles of original statements/exports, plus a previously approved invoice or a hand-checked example of how it is calculated.
- The relationship between producing meters, receiving accounts and allocated shares, along with contract rates/discounts and effective dates.
- The person authorized to grant portal access and handle MFA/session renewal. We will arrange credential transfer through the secure account vault; please do not send passwords or browser cookies in this inventory.

A list of utility names and states is enough to start triage. Unknown items can be marked pending. We will identify which groups already fit an existing connector, which need additional parsing, and which need new portal support before enabling automatic invoices.

This is a prepared request, not a message already sent to Norwich.
